> אפליקציית מוזיקה בהשראת Spotify.

אפליקציה חיה הכוללת חיפוש שירים, יצירת פלייליסטים, ספריית משתמש, לוג פעילות ועוד.

- פיתוח צד לקוח באמצעות React ו-Redux  
- צד שרת פותח עם Node.js, Express ו-MongoDB כבסיס נתונים  
- תומכת בעדכונים חיים באמצעות socket.io  
- זמינה כאפליקציה עם תמיכה ב-PWA  
- עושה שימוש ב-react-youtube API וב-YouTube API להיצע רחב של שירים
